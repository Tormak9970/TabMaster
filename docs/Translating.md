# How to help the project by improving a language you know

You don't need to code. TabMaster translations are done on Crowdin, in the browser.

## Fix or improve an existing translation

1. Open the project: https://crowdin.com/project/tabmaster
2. Sign in (free account) and click your language.
3. Click **Translate All** (or pick a file, then `strings.json`).
4. Find the string you want to fix. Use the search box at the top to find it by text.
5. Type the better translation in the box and click **Save**.
6. Done. Crowdin opens a pull request with the changes automatically. A maintainer merges it.

## Tips

- Left side shows the English original. Right side is where you type.
- Keep placeholders exactly as they are, like `{0}` or `%s`. Don't translate or remove them.
- Keep it short. The text has to fit on a Steam Deck screen.
- Not sure about a word? Add a comment on the string, or vote on someone else's suggestion.
- Use the same words the Steam client uses in your language, so it feels familiar.
- Please don't use machine translation without checking it.

## Your language isn't listed?

Open an issue on GitHub and ask for it. We'll add it to Crowdin.

## Prefer GitHub?

Don't edit `src/i18n/<locale>.json` by hand. Those files are overwritten by Crowdin. Only the English source, `src/i18n/strings.json`, lives in the repo, and it is generated by `scripts/dump-strings.js` (build the plugin first, then run the script).
